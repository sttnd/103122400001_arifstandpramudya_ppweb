    Alur program

    1. Event klik pada tombol Muat pengumuman menjalankan XMLHttpRequest secara asynchronous.
    2. Program memeriksa readyState dan status HTTP. Jika status berhasil, isi responseText ditampilkan pada elemen pre.
    3. Event klik pada tombol Ambil peserta menjalankan Fetch sesuai sumber yang dipilih.
    4. Program memeriksa response.ok, membaca JSON, lalu menampilkan maksimal tiga nama dan email dari response.
    5. Selama request berjalan, tombol request dinonaktifkan. Catatan dan tombol hitungan tetap dapat digunakan.

    Data direktori berasal dari response API. Nama peserta tidak ditulis secara manual pada kode tampilan.
